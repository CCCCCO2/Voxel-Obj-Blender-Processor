# MagicaVoxel-Blender-Pipeline

这是一个 专为 MagicaVoxel -> Blender -> 游戏引擎 工作流程设计的 Blender Extension。它集成了一系列针对 MagicaVoxel 导出模型的处理工具，可自动完成网格清理、UV 处理、材质整理、贴图处理以及资源导出等操作，帮助模型快速进入 Unity 等游戏开发流程。

目前插件包含以下功能模块：

- Voxel Cleanup
	- 清理 MagicaVoxel 导出的 OBJ 模型
	- 有限融并（Limited Dissolve）
	- 合并重合顶点
	- 删除松散几何
	- 清除法线数据
	- 平面着色
	- 自动设置原点
- UV Tools
	- 对指定集合执行 Cube Projection
	- 自动应用材质
	- 将 Mapping 节点的 UV Scale 烘焙到模型 UV
- Material Tools
	- 根据贴图自动重命名材质
	- 修复重复材质
- Export Tools
	- 按 Collection 批量导出 FBX
	- 支持自定义输出目录
- Object Group Tools
	- 创建物体分组，保留所选对象的内部层级
	- 加入已有组、移出组、选择整组、解散组

### 物体分组操作

- **创建新组**：选择需要分组的物体，最后选中的活动物体决定目标集合。仅重新挂接没有选中祖先的对象。这些对象及全部后代实际移动到目标集合，并移除其他集合归属
- **加入已有组**：选择待加入对象，再将目标组根节点（或组内成员）设为活动物体。已在该组内的对象保留内部层级，新成员及其后代加入该组。整个组统一移动到活动物体的目标集合
- **移出组**：只选择需要移出的成员，不要同时选择组根节点。成员及其子树提升到最近一层组的父级，集合归属不变
- **选择整组物体**：选中当前组根节点及全部可选后代；隐藏或不在当前视图层中的成员可能无法选中
- **隐藏整组物体**：遍历所有选中的组根节点或成员，对所属组去重后，隐藏组根节点及全部后代。支持同时操作多个组，无需活动物体，未分组物体会跳过
- **显示整组物体**：恢复所有选中物体所属组的根节点及全部后代的视图显示，无需活动物体。整组隐藏后，可在大纲视图中选择隐藏的组根节点或成员，再点击此按钮来恢复显示
- **解散组**：删除当前组的根节点，将直接子物体提升到其原父级，保留物体、内部层级和集合归属

> 组根节点在 Blender 中使用纯轴空物体（Empty）实现，组按该层级识别。嵌套分组默认定位最近一层，管理外层组时请直接激活外层组根节点。如果活动物体属于多个集合，优先使用当前集合（前提是它包含活动物体），否则使用活动物体的第一个所属集合。创建和加入操作会迁移后代，包括未选中的后代


注意事项：

- 这些操作面向静态模型，保持重新挂接对象的世界变换，带约束或动画的层级应另行检查
- 若移出或解散会将带剪切变换的成员放到场景根级，操作会取消并提示先整理父级旋转和非均匀缩放，避免模型变形
- 支持 Blender 撤销。

## 安装方法

**版本兼容性警告**：本项目主要维护 Blender 4.2+ Extension，旧的脚本仅包含 Voxel Cleanup 功能。如要使用完全功能请使用 Blender 4.2 及以上版本

#### Blender 4.2 及以上版本

 请使用 Blender Extensions 的 .zip 扩展插件</br>

1. 下载 .zip 扩展插件
2. 在 Blender 中选择“编辑”  -> “偏好设置...” -> “插件” -> “从磁盘安装...”，找到下载的插件安装


#### Blender 4.2以下版本

请使用传统 .py 脚本文件

**不完全功能警告**：传统脚本仅包含 Voxel Cleanup 功能，暂时没有更新维护的计划

1. 下载脚本
2. 在 Blender 中打开“文本编辑器”视图：
  - 选择“打开”
  - 找到并选择下载的脚本文件载入
  - 点击“运行脚本”
